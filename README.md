# 🎬 CINEPHY — Curated Cinema Archive

**CINEPHY** is a cinematic movie discovery web application crafted for film lovers. Featuring an editorial aesthetic, curated spotlights, deep search and filtering, playable HD trailers, and full film dossiers.

---

## ✨ Features

- **✦ Curator's Spotlight:** Dynamic widescreen hero section with featured rotating masterpieces, director credits, and mood tags.
- **🔍 Smart Search & Categorization:** Search across titles, directors, cast members, and themes, with sorting by Rating, Year, and Runtime.
- **🏷️ Curated Collections & Genre Filters:** Filter films by All Genres, Sci-Fi, Action, Thriller, Drama, Romance, Animation, or browse 8.5+ Masterpieces and Mind-Bending selections.
- **🎬 35mm Poster Cards:** 2:3 ratio film cards with ambient rim lighting, rating badges, watchlist bookmarks, and instant hover actions.
- **▶️ Official HD Trailer Lightbox:** Built-in responsive cinema player to preview official trailers without leaving the site.
- **📋 Film Dossier View:** Full expanded modal detailing synopsis, principal cast, director breakdown, runtime, and release year.
- **♥ Persistent Watchlist:** Save films to your personalized watchlist stored locally in your browser.
- **🎲 Curator's "Surprise Me" Pick:** Instant random masterpiece discovery button.

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/kiran-madhav/cinephy.git
```

### 2. Navigate to the project directory

```bash
cd cinephy
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser at the local URL displayed in your terminal (typically `http://localhost:5173/`).

---

## 📦 Build for Production

```bash
npm run build
```
